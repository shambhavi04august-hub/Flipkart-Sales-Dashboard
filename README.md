# 📊 Flipkart Sales Dashboard

## 🚀 Project Overview

The **Flipkart Sales Dashboard** is an interactive data visualization project designed to analyze sales performance through key revenue, order, category, and order-status metrics.

The dashboard provides a concise view of overall business performance and helps identify sales trends, high-performing categories, and order fulfillment patterns.

---

## 🎯 Project Objectives

* Analyze overall sales revenue and order performance
* Track monthly sales trends
* Identify the highest-performing product categories
* Analyze order delivery and return status
* Monitor Average Order Value (AOV)
* Provide an interactive and easy-to-understand sales dashboard

## 📊 Dashboard Visualizations

### 1. Monthly Sales Trend

The dashboard tracks monthly revenue from **January to June**.

| Month    | Revenue |
| -------- | ------: |
| January  |   ₹5.2L |
| February |   ₹5.8L |
| March    |   ₹6.5L |
| April    |   ₹7.1L |
| May      |   ₹8.4L |
| June     |   ₹9.6L |

The dashboard shows an **overall upward trend in monthly sales revenue**.

---

### 2. Category-Wise Sales

| Category       |  Sales |
| -------------- | -----: |
| 📱 Electronics | ₹18.4L |
| 👗 Fashion     |  ₹9.1L |
| 🏠 Home        |  ₹6.7L |
| 💄 Beauty      |  ₹4.2L |
| 🛒 Grocery     |  ₹4.2L |

**Electronics** is the highest-performing category in the dashboard.

---

### 3. Order Status

| Order Status  | Percentage |
| ------------- | ---------: |
| ✅ Delivered   |        78% |
| 🚚 In Transit |        15% |

The majority of orders are delivered, while 7% are shown as returned.

## 🔍 Key Insights

* 💰 Total revenue generated is **₹42.6 Lakhs**.
* 📦 The dashboard records **8,340 total orders**.
* 🛒 Average order value is **₹511**.
* 📈 Monthly revenue increases from **₹5.2L in January to ₹9.6L in June**.
* 📱 **Electronics** contributes the highest category-wise sales at **₹18.4L**.
* 👗 Fashion is the second-highest category at **₹9.1L**.
* 🏠 Home contributes **₹6.7L**.
* 💄 Beauty and 🛒 Grocery each contribute **₹4.2L**.
* ✅ **78% of orders are delivered**.
* 🚚 **15% of orders are in transit**.
* 🔄 **7% of orders are returned**.
* 📊 The overall dashboard indicates positive monthly sales growth.
